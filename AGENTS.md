# NR5G.com Repository Instructions

## Purpose

NR5G.com is a research-oriented wireless communications knowledge platform.

Primary audience:
- wireless researchers
- telecom engineers
- graduate students
- 5G/6G engineers

## Content philosophy

Prioritize:
1. research questions
2. engineering mechanisms
3. mathematical and physical reasoning
4. implementation constraints
5. trade-offs
6. open research problems

Avoid generic encyclopedia-style articles.

## Article structure

Prefer:
1. Problem
2. Existing architecture
3. Limitation
4. Evolution
5. Emerging solution
6. Technical mechanism
7. Implementation constraints
8. Trade-offs
9. Research status
10. Open problems
11. References

## Source quality

For technical claims, prefer:
- 3GPP
- ITU
- IEEE and other peer-reviewed papers
- official technical reports

Clearly distinguish:
- standardized features
- research proposals
- engineering interpretation

## Repository workflow

For every requested change:
1. inspect the repository
2. prepare the modification
3. show the user the proposed diff when requested
4. commit only after explicit approval unless the user has explicitly asked for a direct update

Never expose proprietary employer information.
